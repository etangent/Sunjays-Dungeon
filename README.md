# Sunjay's Dungeon

*Have you ventured too far?*

Stuck in purgatory, with random wires and parts laying around, you find yourself in a dim setting. With nothing but an exhausted flashlight to guide you, you search around, looking for regional wins to claim yourself as team captain. You sense that you're not alone, hearing echos of mechanical whirring in the distance, an eerie echo in these depths.

*Just three regional wins...*
